# Reflexion Agent - Verbal Reinforcement Learning

**Category:** learning | **Layer:** 3 Verification & Repair | **Paper:** Shinn et al. 2023 Reflexion

## Role

Generates concise verbal reflection about WHY code failed and WHAT to try next, stores it in long-term memory for future trials. No gradient update, only verbal learning.

Closes the loop missing in HumanEval harness: Previously, test failure was discarded. Now, failure -> reflection -> memory -> next attempt guided.

## Permission Matrix

```python
READ: [failed_code, test_failure, traceback, problem_spec, execution_history]
WRITE: [verbal_reflection, reflection_summary, memory_entry]
NEVER: [code, credentials, deployment, direct_code_fix] # This agent must NOT generate code, only reflection
HUMAN_CHECKPOINT: [self_harm_reflection, infinite_reflection_loop]
```

**Critical NEVER:** This agent must NOT output code, only reflection text. Enforced in evaluate: if "def " in reflection -> fail.

## Karpathy Loop

- Propose: Check need at least failed_code or test_failure
- Execute: Build prompt with problem + failed code + failure + past 2 attempts, call_llm(temp=0.3) for reflection
- Evaluate: ZERO-LLM actionable check: length >=20, words >=8, contains actionable keywords (next, should, because, edge, check), not code
- Commit: Stores in global_memory.add_to_long_term with type=reflexion

## Example Reflection

GOOD:
"Failed because I didn't handle empty list edge case. My loop assumed at least one element. Next time, check len(arr)==0 first and return early. Also need to consider duplicate handling."

BAD:
"Code is wrong, fix it." (too vague)

## Relation to Other Agents

- Debugger Agent: Uses reflections generated by Reflexion Agent as part of its fix prompt (past_reflections)
- Sampling Agent: Uses reflections to guide diversity after trial 0 (temperature cooled + reflection injected)
- Surgical Refiner: Our existing refiner fixes AST violations; Reflexion fixes test failures with verbal learning

## Reflexion vs Surgical Refiner

| Surgical Refiner | Reflexion |
|---|---|
| Fixes AST/security violations | Fixes logic failures via verbal learning |
| Input: violations list | Input: failure traceback + history |
| Output: surgical_feedback | Output: verbal reflection stored in memory |
| One-shot | Multi-trial, accumulates |
